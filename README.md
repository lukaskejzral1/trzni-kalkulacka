# Tržní kalkulačka

Semestrální projekt – konzolová aplikace v C# (.NET 10).

Program pro lineární poptávku `QD = a - b·P` a nabídku `QS = c + d·P` spočítá tržní rovnováhu, cenovou elasticitu poptávky a nabídky, vypíše tabulku pro různé ceny (převis poptávky / nabídky) a nakreslí barevný graf přímo do konzole.

Spuštění:

```
cd TrzniKalkulacka
dotnet run
```
